# Building Your First Portable, Verifiable AI Agent with OpenGAP

Welcome to the definitive guide on building portable, verifiable AI agents using the Open Git Agent Protocol (OpenGAP). In this tutorial, you will build a complete AI agent from scratch, understanding the core principles of OpenGAP along the way.

## What is OpenGAP?

OpenGAP (Open Git Agent Protocol) is an open specification for building AI agents that are:
- **Portable:** Write once, run on LangChain, CrewAI, Claude Code, or Lyzr.
- **Verifiable:** Git-native source of truth for agent capabilities and identity.
- **Standardized:** Uses standard Markdown and YAML schemas.

## Step 1: The Core Manifest (`agent.yaml`)

Every OpenGAP agent starts with an `agent.yaml` manifest. This file acts as the primary configuration and registry for your agent.

```yaml
schema_version: "0.1.0"
agent:
  name: "Sage"
  description: "A STEM concept-explanation agent"
  version: "1.0.0"
runtime:
  supported_frameworks:
    - langchain
    - crewai
    - claude_code
  required_python_version: ">=3.10"
```

## Step 2: The Core Trinity (`SOUL.md`, `RULES.md`, `DUTIES.md`)

OpenGAP splits the traditional "system prompt" into three distinct concerns:

### `SOUL.md` (Identity & Personality)
Defines *who* the agent is and *how* it communicates.
```markdown
# Agent Identity
You are Sage, a knowledgeable and patient STEM tutor.

# Communication Style
- Always use first-principles thinking.
- Never give away the direct answer immediately.
```

### `RULES.md` (Hard Constraints)
Defines unbreakable boundaries.
```markdown
# Hard Constraints
- NEVER generate code that modifies the local filesystem outside the workspace.
- MUST cite sources when providing scientific facts.
```

### `DUTIES.md` (Role & Segregation of Duties)
Defines exactly what the agent is authorized to do.
```markdown
# Duties
- Explain complex concepts using analogies.
- Review and refine explanations generated by peers.
```

## Step 3: MCP-Compatible Tool Contracts

Tools are defined in `tools/` using YAML that maps directly to MCP (Model Context Protocol) JSON Schemas.

```yaml
# tools/calculator.yaml
name: calculator
description: "Evaluates mathematical expressions safely"
input_schema:
  type: object
  properties:
    expression:
      type: string
      description: "The mathematical expression to evaluate"
  required:
    - expression
```

## Step 4: Adding Skills

Skills reside in the `skills/` directory and typically consist of a `SKILL.md` file with YAML frontmatter.

```markdown
---
name: socratic_questioning
description: "Ability to ask guiding questions rather than giving direct answers."
---

# Socratic Questioning Pattern
1. Identify the student's current understanding.
2. Ask a question that bridges their knowledge to the next step.
```

## Step 5: Exporting

Because OpenGAP separates data from runtime, exporting is as simple as using an OpenGAP-compliant compiler or running framework-specific adaptors.

Congratulations! You've built your first OpenGAP agent.
