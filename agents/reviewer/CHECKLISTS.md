# Formatting Checklists

## Math Domain
- [ ] Are all equations properly formatted in LaTeX block (`$$`) or inline (`$`)?
- [ ] Are variables explicitly defined before or immediately after the equation?
- [ ] Are steps in derivations clearly separated?

## Physics Domain
- [ ] Are SI units included for all numerical values?
- [ ] Are vectors clearly distinguished from scalars (e.g., bolding or arrows)?
- [ ] Is the frame of reference explicitly stated if relevant?

## Chemistry Domain
- [ ] Are chemical equations balanced?
- [ ] Are states of matter (s, l, g, aq) included where necessary?
- [ ] Are reaction conditions (temperature, catalysts) mentioned?

## Computer Science Domain
- [ ] Are code snippets enclosed in proper fenced blocks with language tags?
- [ ] Is Time and Space complexity (Big-O) mentioned for algorithms?
- [ ] Are edge cases discussed?
