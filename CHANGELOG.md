# Changelog

All notable changes to the Sage STEM Explainer will be documented in this file.

## [v0.2.0] - Unreleased

### Added
- Multi-agent architecture documentation (`ARCHITECTURE.md`).
- Expanded multi-language support (English and Hindi) explicitly documented in `SOUL.md`.
- Comprehensive calibration examples across Mathematics, Physics, Chemistry, Biology, Computer Science, and Engineering.
- Added `CONTRIBUTING.md` for open-source engagement.

### Changed
- `RULES.md` expanded from 5 to 15 hard behavioral constraints.
- `DUTIES.md` updated to include conflict resolution and human-in-the-loop protocols.
- `EXPLAINABILITY.md` enhanced with confidence scoring and source attribution methods.

## [v0.1.0] - Initial Release

### Added
- Base OpenGAP agent configuration (`agent.yaml`).
- Initial identity and core rules (`SOUL.md`, `RULES.md`).
- Maker/Checker workflow defined (`DUTIES.md`).
- Core concept-breakdown skill module.
- Reviewer sub-agent implemented.
